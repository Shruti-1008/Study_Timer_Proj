# 📚 Study Timer

A simple and colorful Pomodoro-style study timer built using **HTML, CSS, and JavaScript**.

The goal of this project is to help students stay focused during study sessions while keeping track of completed sessions and total study time.

## ✨ Features

* ⏱️ 25-minute study timer
* ▶️ Start the timer
* ⏸️ Pause the timer
* 🔄 Reset the timer
* 🎉 Notification when a study session is completed
* 📊 Tracks completed study sessions
* ⏰ Tracks total study time
* 🎯 Daily study goal
* 📱 Responsive design for smaller screens
* 🎨 Colorful and modern UI

## 🛠️ Technologies Used

* **HTML5** — Structure of the website
* **CSS3** — Styling, colors, layout, and responsive design
* **JavaScript** — Timer functionality and session tracking

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Use **Live Server** to launch the website.
5. Click **Start** and begin studying! 📖

## 🎯 How It Works

The timer starts at **25 minutes**.

When the timer reaches `00:00`:

* The study session is counted as completed.
* Total study time increases by 25 minutes.
* A notification appears.
* The timer stops.
